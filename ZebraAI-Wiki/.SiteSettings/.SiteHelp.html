Real CSS Data will only available in PROD. Synthetic is available in both environments.

For an experiment to be available in the API, you must request access from the My Expeiments view in ZebraAI.

User Roles and Access

ZebraAI requires that users have a corporate account in order to use the site. Furthermore, the site uses Eligibility Roles (from CoreIdentity) to determine which rights and feature access are granted to users.

For access requests, please use the following link and request a membership. Refer to the table below for a description of available roles:

Role Name Role Description Who can be a member
Reader This role gives users the ability to run experiments which leverage real/live/css data. CE&S Employees
Contributor This role gives users Reader access and also allows them to collaborate on and share experiments with others. CE&S Employees
Approver This role gives users the ability to review/approve/reject prompts/experiments for use on real/live data. Compliance Team + Select CSS SBU members
Admin This role allows access to ALL site management features. Select GCS/CXA/Dev team members

Environments

ZebraAI uses two environments: PROD and PPE(UAT/Staging). Only PROD will have access to real/live data.

The PROD environment can be accessed using https://aka.ms/zebraAI.

The PPE(UAT/Staging) environment can be accessed using https://aka.ms/zebraAI-PPE.
