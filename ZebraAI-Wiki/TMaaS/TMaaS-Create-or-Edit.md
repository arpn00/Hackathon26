# Creating or Editing Models

TMaaS Provides the same experience for both creating a new model or editing an existing model. When Editing an existing model the editor is prepopulated with the model you intend to edit.  When creating a new model all data fields are blank.

![Create-Model](/wiki/imgs/TMaaS-Create.png)

##Buttons
Selecting the **Estimate case count** button will trigger the calcuation of the number of cases which will be processed by the model.  
When enabled, selecting the **Submit model** button will submit your model for execution.  
Selecting the **Cancel** button will cancel the current creation or editing session, abandoning all changes.  

##Basic Info.  

The Basic Info. section is where you provide fundamental information for your model, Name, the purpose of the model, the date range for data included in the model, etc. as seen below.  

![Create-Basic](/wiki/imgs/TMaaS-Create-Basic-Info.png)  

**Model name:** A text field where you can enter or modify the name of your model.
**Model Purpose:** You can select from a number of general purposes from the drop down list as well as add further details in the provided text field.  
**Case created date range from:** and **to:** The model will process the cases where case creation date lies between these two dates.  
**Data sources & text fields:** You can select the data sources to be processed by the model.  
**Select translation options:** You can choose between using only English cases in the model or to have non-English cases translated to English and used in the model.  
**Select fine tuned model:** You can select from a number of specifically tuned models in the drop down list.  

##Common Filters  

![Create-Filters](/wiki/imgs/TMaaS-Create-Common-Filters.png)

**Keyword filters:** You can enter any number of keywords to be used to filter cases to be processed by the model.  
**Survey ratings:** You can filter the cases to be used by the model by their survey ratings, values 1 through 5.  
**Sentiment:** You can filter the cases to be used by the model if they include Chat transcripts or Twitter posts, by the sentiment of those texts.
