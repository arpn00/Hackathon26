# How to Request CoreIdentity role for ZebraAI
In order to use the ZebraAI platform, you will need an assigned role through CoreIdentity. 

## How to request CoreIdentity access to ZebraAI

### 1. Navigate to [CoreIdentity](https://coreidentity.microsoft.com/manage/Entitlement/entitlement/zebraai-lmrc). <br>
![Entitlement](/wiki/imgs/Entitlement.png)
###2. Select **Request Membership**.
### 3. In the **Request Membership** dialog box, select **For Myself** as shown.
![Entitlement request](/wiki/imgs/Entitlement-request.png)
### 4. In the **Select which personal account** field, select the account to use.
### 5. Select the role, such as **Reader** or **Contributor**.
### 6. Type a reason for the permissions request in the **Business Justification** field and select **Submit**.
### 7. The request will be processed within 24-48 hours, and users will receive an email notification after the permission is approved.
