# Add Experiment API
The Add Experiment API page lets you request an API Endpoint for your experiment.  

##To request an API for your experiment
1. Navigate to "My Experiments." 

![my experiments.png](/.attachments/my%20experiments-2b811109-2ec1-4444-8a84-f45c62671091.png)

2. Find the experiment you want to request API for and click the connector icon under "Actions."

![api request.png](/.attachments/api%20request-5e2e3bb7-e864-4f02-8af1-bed97e869682.png)

3. Complete the Add Experiment API form and click submit. 
  
![Add API](/wiki/imgs/Add-API.png)  

The API request form includes a few questions to tell the ZebraAI Team the intended value of accessing the experiment through an API as well as the anticipated data volume that they should expect once the API Endpoint is provisioned. If you aren't sure, feel free to make an educated guess. Approval and API provisioning is not dependent on the anticipated ROI or the value of the experiment but may be withheld if an ROI is not shared or readily understood.   
  
If you wish to access the API through an Application, please include the **Client ID** for the application as registered in Azure **Entra ID**.  You will need to have an app registration in the Microsoft tenant. 
 
Please also select the platform(s) from which you will be calling your experiment.  The selections include:
- Copilot
- Excel
- PowerApp
- PowerAutomate
- PowerBI
- Web App
- Web API
- Windows App
- Console App
- Other  
  
Once the form is complete and you have acknowledged that you will comply with the ZebraAI Site and API usage guidelines by checking the check box, the **Submit** button will be enabled.  
  
Pressing the **Submit** button will submit your request.  
Pressing the **Cancel** button will close the page returning you to the [My Experiments](/Get-Started-With-ZebraAI/Navigate/My-Experiments) page.
