## Attributes
In order to enable the submit button there are a few data fields to be completed. **Note:** you need not justify why you want to use CSS Data for your experimentation. The intent in gathering this information is so that the ZebraAI team can understand what you are hoping to achieve with your experiment.

### Hypothesis
- **Comprehension:** Complete a brief problem statement.  This is the problem you intend to solve through your experiment.
- **Response:** Complete a brief statement on the resolution you hope to ultimately achieve.
- **Outcome:** Include the desired (measurable) outcome for your experiment.
- **Outcome:** Include how you intend to measure the outcome.  

### Experiment Context
- **Lifecycle Stage:** select from the list the stage that best reflects how far along you might be in your experimentation process.  
- **Target Audiences:** select the teams you believe will benefit from the implementation of the results of your experimentation in a product that may be used by those teams.
- **Target Business Units:** select the Business Units that will benefit from the implementation of your experiment.
- **Impact Metrics/ROI:** Identify the metrics you will be using to measure the benefit to be gained by implementing your experiment. For example, you might seek to reduce the average time spent by Engineers to resolve a type of case.
- **Initiative Driver/Business Justification:** Provide a brief statement of the business value you hope to achieve through the implementation of your experiment. For example, you might wish to reduce the time to resolve a case by 20%.

More about the data stored for ZebraAI can be found in [Experiment Attributes](/Reference/ZebraAI-Experiments/Experiment-Attributes).

At the bottom of the screen there is an acknowledgement check box which you must check to enable the **Submit for Approval** button.  
  
- **Submit for Approval:** Does as the name suggests and will submit the experiment for approval to use CSS Data.  
- **[Run An Experiment](/Get-Started-With-ZebraAI/Run-An-Experiment)** Opens the Run Experiment screen which allows you one more chance to confirm that your experiment is complete and running as you expect, prior to submitting for approval.  
  


## Approval Process
  
After a user submits an experiment for approval to use CSS data, the experiment is locked and can't be edited. If the user tries to edit the prompt, the pop-up notification, "Cannot edit in read-only editor" will appear.
  
- If the experiment is rejected by the approval process, it is unlocked and available again for edits.  
- If the experiment is approved, the model and prompt information are locked and unavailable for edits. However, the name of the experiment, its sharing level and the parameters that are specified in the experiment can be edited.  
- **[Approval Process](/Reference/ZebraAI-Platform/Approval-Process):** Understand the criteria and process for approving AI experiments that use CSS data sources.
