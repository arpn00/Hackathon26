# Revoke Experiment(s) for use on Real Data

If your experiment is locked and you need to edit your (approved) experiment, or when you no longer need your experiment to access real case data you can revoke access through this screen.  

![Sumbit](/wiki/imgs/Revoke-CSS-Data.png)  
  
Selecting the **Revoke** icon opens a detail screen that displays the details of the selected experiment, as seen below

![Run and Submit](/wiki/imgs/Revoke-CSS-Data-Detail.png)  
  
## Controls  

**Revoke Access** Does as the name suggest and will revoke access to CSS Data for the experiment.  
**Cancel** Will return you to the list view of the Revoke Experiments(s) screen.
