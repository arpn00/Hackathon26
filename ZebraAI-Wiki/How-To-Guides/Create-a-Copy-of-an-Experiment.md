# Create a Copy of an Experiment

This how-to covers creating a copy of an existing ZebraAI experiment. There are many instances where creating a copy of an experiment can be useful: 1) making a copy of someone else's shared experiments so you can make changes for your own usage, 2) creating a copy of your experiment to use for a certain case set (EU, Consumer, etc.), 3) creating a copy of your existing experiment to try new changes without interrupting your existing experiment's CSS access. 

## Steps to create a copy of a ZebraAI experiment: 
### 1. Find an experiment you want to copy. 
### 2. Click the "copy" icon to create a copy of the experiment. 
A. From an experiment tile: 
<br>
![Copy from Tile](/wiki/imgs/CopyFromExperimentTile.png)
<br>
B. From the experiment page: 
<br>
![Copy from Experiment](/wiki/imgs/CopyFromExperimentPage.png)
<br>
### 3. Update the experiment attributes based on your needs. 
### 4. Click "Create Experiment" button at the bottom of the page.
<br>

![Create Copy](/wiki/imgs/CreateExperimentCopy.png)

<br>

### 5. If needed, request CSS Data Usage. 
Instructions: [Request CSS Data Usage](/How-To-Guides/Request-CSS-Data-Usage)
