# Simple User Experience
Simple User Experience (UX) is the most basic of user experiences. For this type of experiment no data is referenced.  Any information shared is inherent in the model you select. In this way the Simple UX is like the [Chat Experience](https://cnfe.visualstudio.com/ZebraAI/_wiki/wikis/ZebraAI/257/Chat)).  Both can be used to help you refine your understanding of [Prompt Engineering](https://cnfe.visualstudio.com/ZebraAI/_wiki/wikis/ZebraAI/141/Prompt-Engineering-with-ZebraAI) and both rely on information attained by the model during its learning process, but the Simple UX provides the opportunity to develop your skills in the context of creating, running, and editing ZebraAI experiments.  

**Note:** Due to the purpose of its use, there is no option available for this experiment to get CSS access.
