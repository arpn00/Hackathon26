# Bring Your Own ADO Wiki Experiments
To access ADO Wiki pages, you can simply reference the ADO Project in which the Wiki pages reside. When you run your experiment, ZebraAI will give you the option to select the Wiki page(s) you wish to use and inject the selection into your experiment.  
  
![BYO ADO Data](/wiki/imgs/BYO-ADO-Wiki-Multi.png)
# Required Information  

To access your ADO data ZebraAI requires 3 pieces of information:
1)	**An ADO Personal Access Token** - To get this token follow the instructions available on [Microsoft Learn](https://learn.microsoft.com/en-us/azure/devops/organizations/accounts/use-personal-access-tokens-to-authenticate?view=azure-devops&tabs=Windows). This is necessary for the authentication process when accessing the Wiki pages for the Project  identified below.
2)	**Organization** - This is your organization as it appears in ADO. Together with the project name, organization identifies the Project to be used by ZebraAI.
3)	**Project** - The project name as it appears in ADO  
4)  **Wiki** - ADO Projects may have several Wiki's.  Select the WIki on which you want to run your experiment.

# API Availability

This experiment type is **not available** through an API call.  

For more information about creating experiments or the individual controls displayed in the screen shot above see [Create An Experiment](https://cnfe.visualstudio.com/ZebraAI/_wiki/wikis/ZebraAI/258/Create-An-Experiment)
