# Bring Your Own Data File Experiments
The Bring Your Own Data File User Experience allows you to include several files into an experiment. There is a fixed **maximum** data volume of **200.0KB** for the file(s) you can include. To reference the data in your experiment, include a reference to **@{InsertDocuments}** in your prompt.  

![BYO File](/wiki/imgs/BYO-Data-File.png)

To include your files in this type of experiment simply drag and drop them in the space provided or follow the **Browse** link to open a File Explorer experience. In all other respects this user experience is like the [Simple User Experience](Simple-UX.md).
   
# API Availability

This experiment type is **not available** through an API call.  

For more information about creating experiments or the individual controls displayed in the screen shot above see [Create An Experiment](https://cnfe.visualstudio.com/ZebraAI/_wiki/wikis/ZebraAI/258/Create-An-Experiment)
