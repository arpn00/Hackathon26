# ZebraAI Data Dictionaries

Welcome to the ZebraAI Data Dictionaries hub. This space centralizes the definitions, mappings, and metadata that power ZebraAI’s commercial, consumer, CPR, ICM, KM, and reporting datasets. Whether you're building prompts, validating data lineage, or onboarding new fields, this wiki provides the data you need to work confidently across ZebraAI’s ecosystem.

If your case results are missing data **that should otherwise be present**, please fill out a bug [submission](https://aka.ms/zebraaifeedback).
