# The **Simple** selector

The **Simple** selector allows the user to chose between display modes of several fields.  WIth **Simple** selected a formated output is displayed as shown below.  

![Simple](/wiki/imgs/Simple-on.png)  

With **Simple** not selected the underlying (formating) code is displayed as shown below.  

![Simple off](/wiki/imgs/Simple-off.png)  


**Note** the scroll indicator on the right. This indicator shows the location in the field that is currently being displayed.
