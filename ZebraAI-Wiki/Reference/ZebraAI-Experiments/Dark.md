# The **Dark** selector

The **Dark** selector allows the user to chose between the display appearance of several fields.  With **Dark** selected output is displayed with light text on a dark background, as shown below.  

![Dark](/wiki/imgs/Dark-on.png)  

With **Dark** not selected the output is displayed with dark text on a light background, as shown below.  

![Dark off](/wiki/imgs/Simple-off.png)  

**Note** the scroll indicator on the right. This indicator shows the location in the field that is currently being displayed.
