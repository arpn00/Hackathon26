# The **Editor Mode** Selector

The **Editor Mode** selector allows the user to choose between two types of text/code field editors.  The image below is of the Monaco editor.  The Monaco editor is a novice friendly editor that provides structure and displays formatting in the fields where it is selected.

![Editor Displayed](/wiki/imgs/Editor-Mode-monaco.png)  

Selecting Text or Builder, depending on which is displayed, allows you to use a classic text or code editor.  

![Editor off](/wiki/imgs/Editor-Mode-text.png)   

**Note** that the text editor is displayed using Dark Mode to further highlight the contrast between the two types of editors

**User Tip** Toggling between the two modes will help you learn the details of the AI Prompt grammar used in Zebra*AI*
