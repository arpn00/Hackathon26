# Permissions to use ZebraAI
Before users can start using ZebraAI, they need to request appropriate permissions via CoreIdentity. There are several types of access roles that are available. 

## Common roles:  
- **Reader**: To run experiments that others have created and shared (but not create your own experiments).  

- **Contributor**: To create and run experiments that use either synthetic data or CSS data. **This is the most common role that most users need.** 

## Special access roles: 
- **TPIDFilterUser:** Select users who are permitted to use TPID in filter criteria.
- **HighVolumeProcessor:** Select users who have higher limits for daily case loads.


## Administrative roles:
**NOTE: Approver**, **API Approver**, and **Admin** Entitlements are **restricted** to the ZebraAI Team and their specific designees. **Do not request** these access levels without contacting the ZebraAI Team.  
- **Admin**: To access all features on the platform.  

- **Approver**: To approve experiments submitted to upgrade from using synthetic data to CSS data.  

- **APIManager** To create API Endpoints for experiments.
