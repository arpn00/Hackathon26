# Experiment Approval

Once the **Submit for Approval** button has been clicked, a request for CSS Data Use is sent to ZebraAI approvers who validate the experiment using a ZebraAI Experiment Approvers checklist.

While awaiting approval, the tile view of the experiment will be updated to indicate that CSS data has been requested:

![Synthetic](/wiki/imgs/Synthetic-with-Data-Request.png)

Approvers will follow these steps to review and approve the ZebraAI experiment:

1. ZebraAI approvers receive an email with a new request.
2. The approver will log in to the ZebraAI site and access the **Admin > Approve Experiments** section to see the approval requests.
3. The approver will review the experiment.
4. The approver will decide to approve or reject the experiment following the guidelines from this checklist: ZebraAI Experiment Approvers Checklist.
    - If the experiment fulfills the requirements in the approver checklist, the approver clicks on the **Approve** button and an email notification is sent to the creator of the experiment.
    - If the experiment does not fulfill the requirements in the approver checklist, the approver provides a reason for the rejection, clicks the **Reject button**, and an email notification is sent to the creator of the experiment.

[Approving ZebraAI Experiments Process](https://cnfe.visualstudio.com/ZebraAI/_wiki/wikis/ZebraAI/106/Approving-ZebraAI-Experiments-Process) provides more information about the approval process.

Once the experiment has been reviewed by an approver, the tile view of the experiment will be updated to include **Approved By** and **Approved On** information and it will be set to use **CSS Data** instead of **SYNTHETIC Data**:
