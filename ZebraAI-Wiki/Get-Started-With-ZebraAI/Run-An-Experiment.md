# Run An Experiment

![Run Experiment](/wiki/imgs/Run-Experiment-Simple.png)


The above is the simples form of an experiment to run.  Depending upon the user experience of the experiment not information or functionality will be displayed.  

## Edit  

The **Edit** icon opens the [Settings Editor](/Reference/ZebraAI-Experiments/Settings-Editor).

## Submit  

Once you have satisfied the input requirements of the user experience, the **Submit** button will be enabled. Press **Submit** to run the experiment. 

### Experiment Results Control Buttons

There are two buttons available on the right side of the Results section of the Run An Experiment page, see below.  These buttons are **Copy** and **Render** and are limited in effect to only the Results section of the page.

![Experiment Results](/wiki/imgs/Experiment-output-controls.png)

**Copy** places a copy of your experiment results in the paste buffer.

**Render** is only displayed if your results include Mermaid code. if pressed the **Render** button opens the [Mermaid](/Reference/Prompt-Engineering/Mermaid) viewer in which the resulting Mermaid diagram is displayed.

## Update  

The **Update** button saves any updates made to the experiment.

## Chat  

When the experiment is run and results displayed, the **Chat** button will be enabled.  Press **Chat** to open a ChatGPT session, prepopulated with the results of the experiment.

## Clear  

The **Clear** button clears the results of the experiment, leaving the experiment ready to be rerun.  

## Copy  

Pressing the **Copy** button opens Copy AI Experiment populating the screen with a copy of the experiment.  

## Input  

Using the **Input** selector allows the user to display the raw (encoded) input.

## Common Controls

Controls like the Source and Simple selectors are common to several features in ZebraAI, the common controls used in the Run Experiment experience include:

- [Source](/Reference/ZebraAI-Experiments/Source): used to toggle the formatting of the GPT response.   
- [Simple](/Reference/ZebraAI-Experiments/Simple): used to toggle the experiment results between raw and formatted display.  
- [Dark](/Reference/ZebraAI-Experiments/Dark): used to toggle between light and dark modes will using the text editor.  
- [Provide Feedback or File Bugs](/Community-and-Support/Provide-Feedback-or-File-Bugs): to report a bug or otherwise provide feedback to the Zebra*AI* team.
