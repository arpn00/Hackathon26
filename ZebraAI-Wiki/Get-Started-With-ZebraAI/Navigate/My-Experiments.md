# My Experiments
The My Experiments screen lets you create a new experiment or manage aspects of your existing experiments.  
  
![Manage My Experiments](/wiki/imgs/Manage-MY-Experiments.png)  
  
The [**Create New Experiment**](/Get-Started-With-ZebraAI/Create-An-Experiment.md) button takes you to the Create Experiment page where you can create something new.  
  
The experiment list displayed includes both experiments that you own as well as experiments that have been shared with you. You can limit the list by entering a filter term in the provided field. In addition, there are two controls that allow you to limit the list of experiments as displayed.  
  
The **Active** toggle lets you limit the list to only active experiments. To view **deleted experiments** set the toggle to **off**.  
The **Owner** toggle lets you limit the list to only experiments you own.  
  
# Indicators  
  
An icon in the **Locked** column indicates that the prompt is locked and cannot be edited.  
An Icon in the **Real Data** column indicates that the experiment has been approved to use real CSS Case data.  
An Icon in the **API** column indicates that a request for an API endpoint has been filed for the experiment or that an endpoint has been provisioned for the experiment.  
 
# Icon Know-how
  
![Manage My Experiments Icons](/wiki/imgs/Manage-MY-Experiments-Icons.png)  
  
[Run Experiment](/Get-Started-With-ZebraAI/Run-An-Experiment) icon lets you execute your experiment.  
[Request CSS Data](/How-To-Guides/Request-CSS-Data-Usage) icon lets you request CSS data access for your experiment.  
[Add API](/How-To-Guides/Add-Experiment-API) icon lets you file a request to have an API endpoint provisioned for your experiment (i.e., Request API access to a specific experiment).  
[Manage API](/Get-Started-With-ZebraAI/Navigate/Manage-MY-Experiment-API) icon lets you manage aspects of your API endpoint including managing access to the experiment through the API, once the endpoint is provisioned.  
**API Requested** icon will be displayed when there is a pending request for an API Endpoing for the experiment.  
**Delete Experiment** icon deletes the experiment.  
**Undelete Experiment** icon re-activates the previously deleted experiments. *This icon is only visible when the **Active** Toggle is **off**, see below.*  
  
  ![Deleted Experiments](/wiki/imgs/Deleted-Experiments.png)   
 
# Experiment Retention

Due to platform limitations, unused experiments will be set to inactive after 30 days of the experiment not being run. This applies to experiments in Private and Shared and means that these experiments will be marked "inactive" and not show up in search results. CSS and API access will be maintained for the experiment, even if it is deactivated. The experiment can be changed back to active in Manage My Experiment.
