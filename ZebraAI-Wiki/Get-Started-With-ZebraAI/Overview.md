# Getting started with ZebraAI 

## What is ZebraAI?  
**ZebraAI is an innovative, secure experimentation platform** where users can test scenarios that **combine the power of Azure OpenAI with real CSS case data in a compliant environment**. It enables prompt‑engineering–driven experiments that safely leverage support insights, helping teams quickly validate ideas. Once an experiment proves successful, it can be transformed into an effective AI‑powered solution for Customer Support. ZebraAI stands out for its commitment to compliance and security. 

## Why is ZebraAI important? 
**ZebraAI democratizes the ability for anyone in CSS to experiment with generative AI and real support data, accelerating innovation while maintaining strict compliance and data safeguards.** It enables quick idea testing and helps transform thought experiments into meaningful solutions that can influence future support tools and workflows.

The platform’s intuitive interface and robust features streamline the experimentation process, making it accessible to both novices and experienced practitioners.  Learn more about the most [common use cases](/Get-Started-With-ZebraAI/Common-Use-Cases) supported by ZebraAI, as well as the [Architecture](/Reference/ZebraAI-Platform/Architecture).  


## What are the key features and benefits of ZebraAI? 
ZebraAI offers a secure environment to create, edit, share, and run experiments with both synthetic and real CSS data, including model parameter tuning and Prompt Flow integration. The platform is designed for speed and collaboration, **helping innovators quickly test ideas and share learnings** within the broader community.

### Primary benefits of ZebraAI:
- **Streamlined Experimentation**: Simplify the process of testing and refining AI models with a user-friendly interface.
- **Collaborative Environment**: Share insights and learn from the community, fostering innovation and collective problem-solving.
- **Ethical AI Practice**: Adhere to Microsoft’s standards for responsible AI, ensuring experiments are conducted with integrity.

### [Key Features of ZebraAI](Key-Features.md)
- **Prompt Engineering Tools**: Tailor prompts to elicit the best performance from AI models.
- **Integration with Azure OpenAI**: Access powerful AI tools and services for robust experimentation.
- **Security and Compliance**: Benefit from a platform built with Microsoft’s stringent security and compliance standards.
- **Community Sharing**: Engage with a network of AI professionals to exchange ideas and best practices.
- [**SkillsBuddy**](/Integrations/Getting-Started-with-SkillsBuddy): Gen-AI app that simulates realistic customer interactions to help advocates practice and improve their communication skills through AI-generated scenarios and feedback.

## Responsible Use of AI
ZebraAI is committed to the ethical deployment of AI technologies. Users are encouraged to consult the list of Restricted Uses to align their experiments with Microsoft’s ethical standards. This guidance is part of our dedication to fostering a responsible AI ecosystem.

## How do I access ZebraAI? 
Navigate to the [ZebraAI home page](https://zebra-ai-web-prd.ait.microsoft.com/home) or preview ZebraAI's future home in [Supportability Hub | ZebraAI](https://supportabilityhub.microsoft.com/zebra-ai). You will need both an assigned CoreIdentity role and access via VPN or GSA. For more information, visit [Set up and Access](/Get-Started-With-ZebraAI/Set-up-and-Access). 

## Is there a learning course for ZebraAI?

Yes, you can take the [Zebra AI Learning Path](https://aka.ms/ZebraAITraining), which currently exists within Microsoft Learning.
This Learning Path will help learners use Zebra AI to browse, create and manage experiments, as well as understand the basics of Prompt Engineering and API usage within Zebra AI.

Course topics include:

- ZebraAI Fundamentals
- ZebraAI Prompt Engineering
- ZebraAI - API Use
