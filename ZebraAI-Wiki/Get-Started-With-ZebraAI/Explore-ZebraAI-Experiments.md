#Explore ZebraAI Experiments

This page focuses on various ZebraAI Experiments. Users can design their own experiments from scratch or leverage sample or shared experiments from the ZebraAI library. 

![image.png](/.attachments/image-b693d4f1-cecb-4b50-b491-953d82782952.png)

##ZebraAI Experiment Levels 
There are 6 levels of experiments:
1. **Showcase Experiments:** Users can choose from a curated list of system-wide experiments showcasing top-tier AI capabilities that have completed a review process and use **CSS Data**, where relevant. Users cannot edit any experiments listed in this level but can make copies for their own use.  
2. **Challenge Experiments:** Users can view experiments in a collaborative innovation space designed to accelerate experimentation and problem-solving across CSS. This section empowers users to post AI experiments as open challenges, inviting peers to contribute, troubleshoot, and enhance solutions in real time.
3. **Hackathon Experiments:** Users can choose from a curated list of experiments that were a part of the Hackathon.
4. **Sample Experiments:** Users can select a list of sample experiments which are intended to showcase different prompts and experiment types. Users are encouraged to use copies of these samples in their own experimentation.
5. **Shared Experiments:** User generated experiments that can be shared with the entire ZebraAI community are listed in this level. Users can view and copy experiments shared by other ZebraAI users. A Shared experiment can be promoted to Showcase Experiments if it is deemed to be a core experiment and completes the required security and testing reviews. Additionally, Shared experiments can use **Synthetic Data** until an experiment is Approved to use **Case Data**. 
3. **Private Experiments:** Users can create their own experiments using only **Synthetic Data**. These experiments are only available to the creator. A Private experiment can be promoted to Shared Experiment once the creator is ready to share.
  
Note:  Experiment Levels can be selected while [creating](Create-An-Experiment.md) or [Edit An Experiment](/Get-Started-With-ZebraAI/Navigate/Edit-An-Experiment) an experiment.  


#Understanding a ZebraAI Experiment Tile
Each experiment level is arranged in a Tile format, and each tile represents an individual experiment.

The tile contains the following information: 
1. Title of the experiment. 
2. Description of the experiment. 
3. Owner: The user who created the experiment. 
4. Approved by: The user who approved the experiment.  
5. Approved on: Date stamp when an experiment was approved. 
Note: **Approved** by and **Approved on** information is populated when an experiment has completed a review process and uses CSS Data.

[**Run An Experiment**](/Get-Started-With-ZebraAI/Run-An-Experiment): Users can execute an experiment and follow further instructions. Available in Showcase, Hackathon, Sample, Shared and Private Experiments. 

**[Create a Copy of an Experiment](/How-To-Guides/Create-a-Copy-of-an-Experiment):** Users can create their own copy of existing experiments as a starting point for newer experiments. Available in Shared Experiments and Private Experiments. 

**Favorite Experiment:** Allows users to add an experiment to their favorites list. Available in Showcase, Hackathon, Sample, Shared and Private Experiments.

**Like Experiment:** Users can like experiments by using this button. This will help determine the effectiveness of an experiment. Available in Showcase, Hackathon, Sample, Shared and Private Experiments. 

**Delete Experiment:** Users can delete an existing experiment. Available in Shared Experiments and Private Experiments. 

[**Synthetic Data Creation Process:**](/Reference/Data/Synthetic-Data-Creation-Process) Represented by a yellow "SYNTHETIC" tag. 

**CSS Data:** Represented by a blue "CSS" tag. 

**Simple Prompt Experiment:** Represented by a grey "GENERAL" tag.
