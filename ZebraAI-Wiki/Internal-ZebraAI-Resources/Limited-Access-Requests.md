#Limited Access Requests for ZebraAI

Limited Access Requests for ZebraAI include TPID Filter Users, High Volume Processors, and Enterprise Processors. In order to grant requests for these roles, the ZebraAI team requires a business justification. These justifications are tracked in case a list is needed for future reporting. 

##Requirements for Justifications
- TPID: a clear indication of why they need it and assurances they are not using it for anything marketing or lead gen purposes
- High Volume: we want an ROI and criticality of their need. We must ensure going beyond 1K per day is absolutely needed since this opens a risk for exploitations should the account become compromised or the user a bad actor.

## Limited Access Requests for Applications
- Users request limited access for applications by using this form: [ZebraAI Limited Access Requests](https://forms.cloud.microsoft/pages/responsepage.aspx?id=v4j5cvGGr0GRqy180BHbR0nYdZiSajJLqk2NfWXeAJhUM05TVFhYV0wyVEMwOEwwWTRIN1VZTFVGMy4u&route=shorturl).
- Essie reviews the business justification for the requests. 
- Once the justification is approved, Essie creates a work item in ADO for Martin to run the script that will give the application the requested permissions.
- The justifications for these requests are tracked in the [spreadsheet](https://microsoft-my.sharepoint.com/:x:/p/v-esjennings/cQoWJKxf8YlOQaM35qRhehXlEgUC1SoTjBKLRA5xxQX9PW63fw) attached to the request form. 

##Limited Access Requests for Users
- Users will request access in CoreIdentity
- Essie, Martin, and Jose can review and respond to these requests via CoreIdentity/MS Approvals
- The justifications will be tracked within CoreIdentity
- To pull a report: 
     - Go to [CoreIdentity](https://coreidentity.microsoft.com/manage/entitlement/entitlement/zebraai-lmrc)
     - Go to the "Request History" tab
     - History Type = Access
     - On the right hand side, select the drop down for "Columns," and make sure "Requestor Justification" and "Approver Comments" are both selected. 
     - Click Export
     - In 5-10 minutes, the resulting csv will be available in Bulk Operation Results
- Note: From January-July 2026, justification notes were kept in [High Volume Processor Entitlement Approvals.xlsx](https://microsoft-my.sharepoint.com/:x:/p/mibrownl/cQqWQhOrOE5PT5OvRY392ZTvEgUCABPumr0Nj6-rKanFR3VVvA)
