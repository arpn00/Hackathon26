# Welcome to ZebraAI!

ZebraAI is a web-based platform that allows you to explore, create, and run artificial intelligence experiments using various data sources. Whether you are a beginner or an expert, you can use ZebraAI to learn more about AI, test your ideas, or develop your skills.

This guide will help you get started with ZebraAI and show you how to use its features. You will find links to the following topics:

* [Overview](/Get-Started-With-ZebraAI/Overview): Learn what ZebraAI is all about.
* [Set up and Access](/Get-Started-With-ZebraAI/Set-up-and-Access): Learn about requirements for accessing the ZebraAI platform
* [Navigate](/Get-Started-With-ZebraAI/Navigate): Learn to find your way around.
* [ZebraAI FAQs](Feedback-and-Support/ZebraAI-FAQ.md): Get your ZebraAI questions answered.

## Popular ZebraAI Functionality

* [Create An Experiment](/Get-Started-With-ZebraAI/Create-An-Experiment): Follow the steps to create a new AI experiment from scratch or from a template.
* [Explore ZebraAI Experiments](/Get-Started-With-ZebraAI/Explore-ZebraAI-Experiments): Learn how to find and use existing and available experiments.
* [Run An Experiment](/Build-and-Experiment/Working-with-Experiments/Run-An-Experiment): Learn how to run your AI experiment and view the results.
* [Edit An Experiment](/Build-and-Experiment/Working-with-Experiments/Edit-An-Experiment): Learn how to modify your AI experiment and save your changes.
* [Request CSS Data Usage](/How-To-Guides/Request-CSS-Data-Usage): Learn how to submit your AI experiment for approval if you want to use CSS data sources.
* [Approval Process](/Build-and-Experiment/Working-with-Experiments/Approval-Process): Understand the criteria and process for approving AI experiments that use CSS data sources.
