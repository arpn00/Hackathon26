## Apollo AI Authoring


[AI Authoring](https://supportabilityhub.microsoft.com/solutions/apollosolutions) provides a consistent, guided workflow for running ZebraAI experiments within Supportability Hub to generate support articles. From supported entry points, users can select from available experiments and execute them on one or multiple cases without leaving the tool. This embedded authoring experience is designed to reduce friction and improve efficiency when generating AI-backed insights.

### Key capabilities of Apollo AI Authoring

*   Access to available ZebraAI experiments from native experiences
*   Guided, consistent workflow aligned with existing Supportability Hub UI patterns
*   Generate self‑help articles for support topics that currently do not have an article mapped to them
*   Generate new self‑help articles for support topics that already have an article, but where the article is not up-to-date

## Case Clusters

The [Case Clusters experience](https://supportabilityhub.microsoft.com/practices/case-clusters) enables users to launch ZebraAI experiments directly from a selected case cluster in Supportability Hub. Case IDs are automatically populated, and experiment results are returned inline within the same experience. This reduces manual handoffs and accelerates insight generation for identifying patterns such as outages or systemic issues.

![Case Clusters](/wiki/imgs/Case-Cluster.gif.gif)

### Key capabilities of Case Clusters

*   Launch ZebraAI experiments straight from a case cluster
*   Automatic population of case IDs
*   In-context viewing of AI-generated results inside Supportability Hub
*   Support for faster identification of large-scale issues and trends

## Case Review

The [Case Review experience](https://supportabilityhub.microsoft.com/practices/case-review-query/all?supportscope=91ca5b37-c1fe-920a-a32e-53c4b9f85a2a) extends the same ZebraAI workflow into individual case reviews. Based on user feedback, this integration allows a broader group of users to apply AI-powered analysis during case-level investigation and validation. Results are displayed directly within the Case Review screen, supporting quicker decision-making without context switching.

### Key capabilities of Case Review

*   Native ZebraAI access from the Case Review screen
*   Support for AI-powered analysis during individual case investigation
*   Inline display of experiment results within Supportability Hub
