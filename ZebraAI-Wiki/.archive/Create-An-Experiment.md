# Create An Experiment

To create a new experiment, users should follow these steps:

1. Select **Create AI Experiment** on the left navigation menu.
On the **Experiment** tab, type a name for the experiment in the **Experiment Name** field and a description of what it will do in the **Description (HTML)** field.
To share the experiment with other users, open the **Share Level** drop-down menu and select **Shared**.
2. On the **User Experience** tab, open the drop-down menu for **Select User Experience**, and select one of the options. 
A description and a preview is provided for each option in the drop-down menu. 
3. On the **Model** tab, open the drop-down menu for **Select Model**, and select one of the options. 
A description and the scenarios that a model is best used for is provided for each option in the drop-down menu. 
4. On the **Prompt** tab, either select an option from the **Copy from sample prompt** drop-down menu or type in their own prompt. 
If users are creating a prompt that will use case data, they can scroll to the bottom of the window for a list of parameter substitutions that are available for Commercial and Consumer cases.
5. On the **Follow-Up Prompt** tab, if a second prompt is needed to follow the first one, either select an option from the Copy from sample prompt drop-down menu or type in a second prompt. If a second prompt isn't needed, leave it blank. Adding a second prompt is optional. 
6. On the **Parameters tab**, either select an action from the **Select Existing Parameters** drop-down menu to populate the parameter values associated with the action automatically or change the parameter values that you feel are appropriate for your experiment by using the sliders. 
For details about a parameter, hover over the information button at the end of the slider for the parameter value.
7. Select **Create Experiment**.

The newly created experiment displays.
