#Guide to Zebra AI
ZebraAI is a web-based platform that allows you to explore, create, and run artificial intelligence experiments using various data sources. Whether you are a beginner or an expert, you can use ZebraAI to learn more about AI, test your ideas, or develop your skills.

This guide will help you get started with ZebraAI and show you how to use its features. You will find links to the following topics:

* [Get started with ZebraAI](Get-Started-with-ZebraAI.md): Learn how to sign up, log in, and navigate the ZebraAI interface.
* [Explore AI Experiments](Explore-AI-Experiments.md): Discover and try out existing AI experiments created by other users or the ZebraAI team.
    * [Data Sources Available](Data-Sources-Available.md): Find out what data sources you can use for your AI experiments, such as images, text, audio, video, or custom data.
* [Experiments](Experiments.md): Learn how to create, run, edit, and submit your own AI experiments using the ZebraAI editor.
    * [Create an experiment](Create-An-Experiment.md): Follow the steps to create a new AI experiment from scratch or from a template.
    * [Run an experiment](Run-An-Experiment.md): Learn how to run your AI experiment and view the results.
    * [Edit an experiment](Edit-An-Experiment.md): Learn how to modify your AI experiment and save your changes.
    * [Submit an experiment to use CSS Data](Submit-An-Experiment-To-Use-CSS-Data.md): Learn how to submit your AI experiment for approval if you want to use CSS data sources.
        * [Approval process](Approval-Process.md): Understand the criteria and process for approving AI experiments that use CSS data sources.
* [Provide Feedback or File Bugs](https://aka.ms/zebraaifeedback): Learn how to share your feedback or report any issues with ZebraAI.
* [Important Links](Important-Links.md): Find links to useful resources and information about ZebraAI.
