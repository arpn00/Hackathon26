# Get started with ZebraAI 

# Introduction 
ZebraAI is a platform on which users can test scenarios that combine the power of AI with data from actual CSS cases. They can use prompt engineering to run experiments that harness the power of Azure Open AI together with secure customer support data in a compliant environment. After an experiment is proven to be successful, it can be turned into an effective AI-powered solution. 

# Permissions to use ZebraAI
Before users can start using ZebraAI, they need to request appropriate permissions on the platform to create and run experiments. There are 4 types of access roles that are available:
**Reader**: To run experiments that others have created and shared but not create your own.
**Contributor**: To create and run experiments that use either synthetic data or CSS data.
**Approver**: To approve experiments submitted to upgrade from using synthetic data to CSS data.
**Admin**: To access all features on the platform; restricted mostly to the ZebraAI Engineering team.

To request permissions, use the following steps:
1.	Navigate to [CoreIdentity - Manage Entitlement (microsoft.com)](https://coreidentity.microsoft.com/manage/Entitlement/entitlement/zebraai-lmrc).
2.	Select **Request Membership**.
3.	In the **Request Membership** dialog box, select **For Myself**.
4.	In the **Select which personal account** field, select the account to use.
5.	Select the role, such as **Contributor**.
6.	Type a reason for the permissions request in the **Business Justification** field and select **Submit**.

The request will be processed and users will receive an email notification after the permission is approved.
