#Explore AI Experiments

This page focuses on various ZebraAI Experiments. Users can design their own experiments from scratch or leverage shared experiments from the ZebraAI library. 

![explore-ai-experiments-img1](wiki/imgs/explore-ai-experiments-img1.png)

##Experiment Levels 
There are 3 levels of experiments:
1. **System Wide Experiments:** Users can select a list of system wide experiments that showcase different AI capabilities that have completed a review process and use **CSS Data**. Users cannot edit any experiments listed in this level. 
2. **Shared Experiments:** User generated experiments that can be shared with the entire ZebraAI community are listed in this level. Users can view and edit experiments shared by other ZebraAI users. A Shared experiment can be promoted to System Wide if it is deemed to be a core experiment and completes the required security and testing reviews. Additionally, Shared experiments can use **Synthetic Data** until an experiment is Approved to use **Case Data**. 
3. **Private Experiments:** Users can create their own experiments using only **Synthetic Data**. These experiments are only available to the creator. A Private experiment can be promoted to Shared Experiment once the creator is ready to share.

#Know-how 
Each experiment level is arranged in a Tile format, and each tile represents an individual experiment.

The tile contains the following information: 
1. Title of the experiment. 
2. Description of the experiment. 
3. Owner: The user who created the experiment. 
4. Approved by: The user who approved the experiment.  
5. Approved on: Date stamp when an experiment was approved. 
Note: **Approved** by and **Approved on** information is populated when an experiment has completed a review process and uses CSS Data.

##Icons Know-how
![explore-ai-experiments-img2](wiki/imgs/explore-ai-experiments-img2.png)

**Run Experiment:** Users can execute an experiment and follow further instructions. Available in System wide Experiments, Shared Experiments and Private Experiments. 

**Edit Experiment:** Users can edit existing experiments which can be leveraged by the community as starting points for newer experiments. Available in Shared Experiments and Private Experiments. 

**Add to favorites:** Allows users to add an experiment as their favorites. 

**Delete Experiment:** Users can delete an existing experiment. Available in Shared Experiments and Private Experiments. 

**Vote Experiment:** Users can vote on experiments using this button. This will help determine the effectiveness of an experiment. Available in System wide Experiments, Shared Experiments and Private Experiments. 

**Synthetic Data:** This icon represents if an experiment is using synthetic data. 

**CSS Data:** This icon represents if an experiment is using real customer support data.
