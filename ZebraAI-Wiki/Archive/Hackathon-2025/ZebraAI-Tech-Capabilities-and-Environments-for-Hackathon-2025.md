# ZebraAI Technology Capabilities and Environments for Hackathon 2025​
## Overview
This wiki provides options, resources, and instructions to Hackathon 2025 participants who want to use ZebraAI in their Hackathon project.

##ZebraAI's Three Environment Tiers  
Participants have three different ZebraAI Environment Tiers to choose from: ZebraAI Core, Copilot Studio, and ProCode Environment. 

The following table can help participants identify which ZebraAI Environment Tier is right for them.

###ZebraAI User Scenarios by Environment
This section gives some examples of what participants can accomplish in each of the environments.

####ZebraAI Core is the right choice if you want to...
- Generate rich, PII‑safe case overviews from notes, email transcripts, and activities.
- Ingest log files using BYOD to extract errors, cluster symptoms, and suggest diagnostic steps.
- Utilize approved experiments outputs via REST API from apps like web app or Teams bots.
- Draft empathetic recovery emails for potential DSATs, with tailored next‑best actions and links to known fixes.

####Copilot Studio (Low Code) is great if you want to...
- Create an agent in Copilot Studio and link my ZebraAI project to answer “how‑to” and troubleshooting questions grounded on KB and product docs; can hand off to live channels with full context when necessary.​
- Trigger targeted, templated outreach (e.g., service incident or hotfix guidance) through flows when certain conditions from telemetry fire, keeping customers ahead of issues.
- Build an internal agent for support engineers inside Teams/M365 that fetches related cases, known issues, and playbooks; generates replies and next steps the engineer can approve before sending them to customer.
- Create an agent that uses case details upon submission (via connector), gathers minimal facts, and finds similar cases with resolutions and produces a structured summary with complete scoping guidance. This information can be directly shared with the customer prior to a live agent starting to work on the case.

####ProCode Environment is for those who want to...
- Aggregate signals, propose mitigations, and log actions with observability.
- Orchestrate specialized agents for classification, KB retrieval, and escalation. Agents mine resolved cases, draft KBs, and validates before publishing.
- Set up agents to call APIs and logs to propose diagnostic steps.
- Create multi-agent team that sets up repro environments, runs scripts, and reports results.
