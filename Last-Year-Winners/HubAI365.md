# HubAI365 — Winner (Last Year)

> Reference writeup of a prior-year winning ZebraAI hackathon project, captured for
> idea-pool context. Sourced from the user-provided project description and the demo
> video transcript. Used to understand what wins and to find non-duplicate white space.

---

## One-liner

**"HubAI for CSS"** (aka.ms/hubai365). An enterprise-grade AI support solution that
**orchestrates multiple technologies** — ZebraAI, Azure AI Foundry, and custom agent
frameworks — to deliver intelligent, adaptive, **role-aware** support experiences. Makes
support "smarter, faster, and more human."

- Keywords: Sentiment Analysis, Case Resolution Acceleration, Troubleshooting Assistant.
- Persona: support engineers (multiple CSS roles) + managers (case review mode).
- Positioning: a **platform/orchestrator**, not a single-component tool.

---

## Core capabilities

- **Intent-Driven Scoping** — interprets case context + user intent to dynamically generate
  troubleshooting steps tailored to the issue.
- **Advanced Diagnostic Analysis** — reviews **logs, configuration files, and telemetry**
  for deep insights → faster root-cause identification.
- **On-Demand Learning** — delivers **micro-lessons / mini courses** in real time so
  engineers upskill without leaving their workflow.
- **Role-Based Personalization** — adapts to multiple CSS roles for a customized experience.
- **Connected Intelligence** — integrates with custom agents + enterprise systems to
  orchestrate complex workflows and escalation paths.

---

## Modes (from the demo)

1. **Troubleshooting mode** — scopes issues using industry best practices; adapts to the
   technology and nature of the issue; builds guided troubleshooters.
2. **Research mode** — analyzes uploaded **logs** instantly, highlighting critical issues
   and giving actionable guidance.
3. **Case Review mode** (for managers) — input a case, get a comprehensive review with deep
   insights into the issue, **customer sentiment**, **engineer performance**, and **product
   team engagement**.

---

## Impact / positioning

Empowers engineers to resolve issues faster, improve accuracy, and deliver exceptional CX
through AI automation, contextual intelligence, and continuous learning. Portrayed as a
transformative agent that helps engineers **restore focus, boost throughput, and build
confidence** via precise scoping, clear troubleshooting, in-depth analysis, and insightful
case reviews.

---

## Why it won (patterns to learn from)

1. **Multi-model orchestration story** — ZebraAI + Azure AI Foundry + custom agents signals
   technical ambition/Innovation beyond a single prompt.
2. **The learning/upskilling angle is genuinely novel** — "mini courses in the flow of
   work" is a differentiator none of the other winners had (grows people, not just cases).
3. **Role-aware, multi-mode** — one tool that reshapes itself for engineer vs. manager
   covers more of the org (Impact + Collaboration).
4. **Deep technical diagnosis** — logs/config/telemetry root-cause is concrete and
   demoable (Feasibility signal).
5. **Aspirational tagline + vanity URL** — "smarter, faster, more human" + aka.ms/hubai365
   feels like a real product.

> Note: the **On-Demand Learning / micro-lessons** capability is the standout white space
> here — closest anyone came to engineer coaching/skill-growth, but bundled inside a broad
> platform rather than being the whole idea.

> Contrast with the others: HubAI365 = **broad engineer-copilot platform (scope + diagnose
> + learn + review)**. Case CPU = manager triage. Hedwig = code-change intel. Transfer Agent
> = handoff. DocuScout = doc-gap prevention. CAREBridge = trust + Azure growth. Six distinct
> white spaces.
